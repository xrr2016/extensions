# Prelook 隐私政策

生效日期：2026 年 9 月 20 日

感谢你使用 Prelook。本政策说明 Prelook 浏览器扩展（下称「扩展」）以及 Prelook 官网（下称「网站」）如何处理你的数据。

一句话概括：Prelook 不收集你的任何个人信息。扩展没有账号体系、不设自有服务器，所有设置与绝大多数处理都在你的设备本地完成。

## 1. 我们收集什么

我们不收集任何个人身份信息。Prelook 不采集浏览历史、不追踪上网行为、不读取通讯录或文件，也不向开发者或任何第三方服务器上传任何数据。

扩展不包含广告、不包含远程代码、不加载外部脚本，全部功能免费。

## 2. 扩展处理的数据

扩展仅在本地处理下列数据，用于实现其核心功能：

- **设置**：你的偏好设置（触发方式、预览窗尺寸、主题、搜索引擎等）保存在浏览器本地的 chrome.storage.local 中，仅存于你的设备，不会上传。卸载扩展即删除。
- **悬停链接的 URL 与目标页内容**：当你悬停、长按、拖动或通过右键菜单触发预览时，扩展会读取该链接地址，并由后台直接向目标网站请求页面内容，用于在预览窗中渲染（可内嵌时用 iframe，禁嵌站点自动切换阅读模式）。该请求不带你的 Cookie（credentials: 'omit'），由扩展直接从你的浏览器发往目标网站，不经过任何中转服务器。
- **链接预热**：当你开启预热后，悬停的链接会通过浏览器原生的 Speculation Rules API 预取或预渲染，由浏览器直接向目标网站发起请求。你可以在扩展「性能」设置中随时关闭。
- **划词搜索与翻译**：当你选中文字并点击搜索或翻译按钮时，选中文字会按你的选择发送给对应的搜索引擎或翻译服务（Google、Bing、DuckDuckGo、DeepSeek、豆包、Kimi、Perplexity、Google 翻译、Bing 翻译等）。这是你主动触发的操作；其中 DeepSeek、豆包、Kimi 三家仅打开其首页，文字由扩展复制到你的剪贴板、由你自行粘贴。
- **追踪参数清理与链接风险提示**：剥离 utm_*、fbclid 等追踪参数、还原中转壳地址、判定链接是否存在仿冒风险，全部在本机完成，不发送任何数据。

## 3. 数据的存储

- 扩展设置存储于浏览器本地存储（chrome.storage.local）；
- 网站的主题与语言偏好存储于你浏览器的 localStorage；
- 以上数据均不离开你的设备。

## 4. 第三方服务

划词搜索、AI 搜索与翻译在你主动触发时，会将你选中的文字发送给你选择的第三方服务。这些服务分别适用其各自的隐私政策：Google（policies.google.com/privacy）、Microsoft Bing（privacy.microsoft.com）、DuckDuckGo（duckduckgo.com/privacy），以及 DeepSeek、豆包、Kimi、Perplexity 各服务官网的隐私政策。

扩展本身不向这些服务之外的任何第三方披露你的数据。

## 5. 权限说明

扩展申请的权限均用于实现核心功能：

- storage：在本地保存你的设置；
- tabs 与 contextMenus：在新标签页打开目标、提供右键菜单；
- `<all_urls>` 主机权限：预览功能需要对任意悬停的链接发起预览请求（请求不带 Cookie）。

## 6. 数据安全

扩展代码开源、全部功能免费，不包含远程代码、不加载外部脚本、不投放广告。由于数据几乎不离开你的设备，本地数据的安全取决于你设备本身的安全状况。

## 7. 你的选择与控制

- 你可以随时在扩展设置中关闭预热、划词搜索等功能；
- 卸载扩展会删除其全部本地数据；
- 网站的主题与语言偏好可在浏览器设置中清除站点数据后重置。
