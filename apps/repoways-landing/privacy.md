# RepoWays 隐私政策 / Privacy Policy

生效日期 / Effective: 2026-10-16

一句话概括：RepoWays 不收集任何个人信息。扩展不申请任何浏览器权限、不发起任何网络请求、不写入任何存储，也不设账号或统计。

In one line: RepoWays collects no personal information. The extension requests no permissions, makes no network requests, stores nothing, and has no accounts or analytics.

## 1. 我们收集什么 / What we collect

什么都不收集。不采集浏览记录、不读取页面内容、不追踪行为，也不向开发者或任何第三方上传数据。扩展代码开源，可自行核验。

Nothing. No browsing history, no page-content reads, no tracking, and no uploads to the developer or any third party. The extension is open source and can be verified.

## 2. 扩展做了什么 / What the extension does

只在 GitHub 仓库页的 `Code` 按钮旁插入一枚 `Ways` 按钮。点开后的每条入口都是按当前仓库 `owner/repo` 现拼出来的普通链接，仅当你亲自点击时浏览器才打开对应第三方网站。扩展本身不抓取、不代理、不上传任何内容。

It inserts a `Ways` button next to `Code`. Every menu entry is a plain link built from the current `owner/repo`; a third-party site opens only when you click it. The extension never scrapes, proxies or uploads anything.

## 3. 权限 / Permissions

零权限。manifest 里没有 `permissions`，也没有 `host_permissions`；不申请存储、标签页、网络或任何主机访问权限。

Zero permissions. The manifest declares no `permissions` and no `host_permissions`.

## 4. 存储 / Storage

扩展不写入任何存储。官网只把语言与深浅色偏好存于浏览器 `localStorage`（键 `repoways-landing-lang` 与 `repoways-landing-theme`），仅存本机、不上报。

The extension writes nothing to storage. The website stores only the chosen language and theme in `localStorage` (keys `repoways-landing-lang` and `repoways-landing-theme`), on-device, never uploaded.

## 5. 第三方网站 / Third-party sites

你点击的条目会带你前往 GitDiagram、DeepWiki、GitHub.dev、StackBlitz 等第三方站点，各自适用其隐私政策。RepoWays 不在你与这些站点之间的请求里加入任何追踪参数或标识。

Clicked entries take you to third-party sites (GitDiagram, DeepWiki, GitHub.dev, StackBlitz, …), each with its own privacy policy. RepoWays adds no tracking parameters or identifiers to those requests.

## 6. 政策更新 / Policy updates

如发生变更，会在此页发布更新版本并注明新的生效日期。

Changes are published on this page with a new effective date.
