四步装好

用离线包安装，适用于 Chrome 与 Edge。

  1. 1

    下载离线包，解压到一个文件夹

  2. 2

    打开 chrome://extensions，在右上角开启「开发者模式」

  3. 3

    点「加载已解压的扩展程序」，选中刚才的文件夹

  4. 4

    打开任意 GitHub 仓库页，Code 左边的 Ways 就是它
