发现清单

高无任何结构化数据（JSON-LD）
源码与 main.js 中均无 application/ld+json。FAQ 区 5 组问答可做 FAQPage 富结果，扩展产品可加 SoftwareApplication + WebSite/Organization（sameAs 指向 GitHub）。影响：错失富结果展示机会。
高首页与隐私页均缺 canonical 标签
两页 <head> 无 <link rel="canonical">。首页应自引用 https://prelook.coldstoneboy.cn/（不用 /index.html），隐私页指向自身；避免 http/https、www 变体并存时权重分散。
高og:image 为相对路径，缺 og:url / twitter:card
og:image 是 ./assets/logo.webp，社交抓取器需要绝对 URL：https://prelook.coldstoneboy.cn/assets/logo.webp；并补 og:url、og:site_name 与 twitter:card 三件套，否则分享到微信/推特/Telegram 可能无图无卡。
中中英双语共用同一 URL，英文内容对搜索引擎不可见
html lang="zh-CN"，英文词条只在 main.js 的 I18N/TITLES 里，需 localStorage 切换；Googlebot 无 localStorage，只能索引到中文版。无 hreflang。若英文是目标市场，应拆 /en/ 独立 URL + hreflang；否则维持中文默认并明确不冲英文 SERP。
中文案宣称「十二项能力」，页面只渲染 9 张功能卡
meta description 与 features.subtitle 都写「十二项」，但 HTML 仅有 9 张卡（侧边栏 / AI 搜索 / 主题外观 三条词条在词典中无对应卡片）。补齐 3 张卡，或把文案改为实际数量，避免描述与内容不一致。
中meta description 不随语言切换
title 会随 applyLang 换成英文（TITLES），description 始终是中文。切到英文时 SERP 片段语言与页面不一致；建议 description 也走双语映射。另：静态 H1「不必点开」与词典「无需等待」不一致，JS 一跑就被覆盖，建议两处对齐。
中二维码 / Ko-fi 图片缺宽高属性（CLS 风险）
weixin.jpg、zhifubao.jpg、kofi.jpg 三个 <img> 无 width/height 或 CSS 定尺寸，虽已 lazy 加载，仍可能在图片到达后引起布局偏移。补上尺寸或给 .sponsor-qr 定高。
低死资源 4 个（未被页面引用）
demo.mp4（809KB）、demo-poster.webp、icon.png、logo.old.webp 不在 index/privacy 中引用。不影响爬取，但建议清理或归档，避免部署体积与仓库噪音。
低无 preconnect / dns-prefetch 到外部域
ko-fi.com、github.com、商店域名均为外部跳转，可在 <head> 加 2-3 条 preconnect，微优化首跳延迟。
低favicon 无 apple-touch-icon；keywords meta 可清理
webp favicon 现代浏览器可识别；iOS 分享需要 apple-touch-icon.png。keywords 已被 Google 忽略，留着无害，删了更干净。

快速行动清单（按性价比排序）

  1. 两页加自引用 canonical（首页用根路径）
  2. og:image 改绝对 URL + 补 og:url / og:site_name / twitter:card
  3. 首页加 FAQPage JSON-LD（5 组问答）＋ WebSite + SoftwareApplication
  4. 二维码/ko-fi 图片补宽高，消除 CLS 隐患
  5. 对齐「十二项」文案与页内卡片数；description 双语化

长期建议：若冲英文流量则拆 /en/ + hreflang；部署后跑 PageSpeed Insights 与 Search Console 验证 CWV 与收录；sitemap lastmod 随内容更新。

验证边界本审计基于本地源码核验（index.html / privacy.html / robots.txt / sitemap*.xml / main.js / privacy.js）。服务端层面（TTFB、缓存头、CDN、HSTS、404 处理、真实 CWV）与搜索引擎收录状态（site: 查询、GSC）无法从本地文件判断，需部署上线后验证。
